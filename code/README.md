# navigation_system — учебный пример ГНСС/ИНС + ЕКФ (EKF)

## Что это
Небольшой, максимально «прозрачный» пример интеграции инерциальной навигационной системы (ИНС) и ГНСС
с использованием расширенного фильтра Калмана (ЕКФ / EKF).

Проект генерирует синтетическую траекторию БПЛА, синтетические измерения IMU (акселерометры/гироскопы)
и периодические измерения ГНСС, после чего сравнивает:
- только ИНС,
- ИНС + ЕКФ (с коррекцией по ГНСС/баро).

## Быстрый запуск
```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt

python -m navigation_system.main
```

После запуска в каталоге `outputs/` появятся графики и файлы логов.

## Структура
- `data_loader.py` — генерация траектории и синтетических датчиков
- `strapdown_integration.py` — упрощённое «страпдаун»-интегрирование ИНС
- `extended_kalman_filter.py` — ЕКФ
- `adaptive_tuning.py` — простая адаптация ковариаций измерений
- `visualization.py` — графики
- `main.py` — сборка эксперимента

## Все сценарии
```bash
python run_all.py
```
